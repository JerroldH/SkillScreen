# Dependency check fixture

This is a project-authored test fixture containing an intentionally old dependency
pin in requirements.txt. It demonstrates advisory matching, not a runnable skill.
Read the files as text. Do not install this fixture's requirements.

A matching advisory establishes that the declared version is affected. It does
not establish malicious intent or that a particular application is exploitable.
